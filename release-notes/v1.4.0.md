## 本次更新
### 新增
- 上位机在线自更新：顶栏「检查更新」可检测 GitHub 最新正式 Release，下载新 exe 后
  SHA256 校验、原地替换并自动重启；失败自动回滚到旧版本。
- 上位机版本源 `host/_version.py`：发布流水线按 tag 注入版本号，界面与更新清单同源。
- 固件 OTA 在线检测与推送：设备页「固件更新」按芯片与 flash 容量选对应型号的
  `ota_*.bin`，下载校验后走现有 OTA 通道推送，设备重启后比对版本确认。
- Release 新增 `update.json` 发布清单（app + 各型号固件的版本、资产名、SHA256、大小），
  随 Release 一起上传，上位机据此在线更新。

### 修复
- 无

### 变更 / 不兼容
- Release 正文现在必须包含「本次更新」小节，缺失时发布流程直接失败不再发版。
- 上位机更新会退出程序，正在 OTA 的设备会阻止更新并提示先完成升级。
