    宏与动作帮助

    宏怎么用

    按键的「上位机动作」选 宏，文本框里一行写一步，按顺序执行；改完点右上角「应用配置」下发。宏只在主机侧执行，设备本身仍会照常发送上面的 HID 键。

    写法作用
    key:Tab发送一个按键或组合键；修饰键用 + 连接，如 key:ctrl+alt+t
    text:hello逐字符输入文本
    wait:500等待 500 毫秒（单位毫秒）
    url:https://example.com用默认浏览器打开网址
    无前缀行按 key: 处理，例如单独一行 enter

    键名对照表

    键名不区分大小写，写界面上显示的名字即可（PageUp 与 pageup 等价）。

    宏里写实际按键
    Tab Enter Esc SpaceTab、回车、Esc、空格
    Backspace Insert Delete退格、插入、删除
    Home End PageUp PageDown行首、行尾、上翻页、下翻页
    Left Right Up Down方向键
    LCtrl / RCtrl左 / 右 Ctrl（ctrl 等同左 Ctrl）
    LShift / RShift左 / 右 Shift
    LAlt / RAlt左 / 右 Alt
    LWin / RWin左 / 右 Win
    F1–F12功能键
    F13–F24原样传给 keyboard 库（设备默认键码即 F13–F22）
    A–Z / 0–9单个字母 / 数字

    完整示例：打开页面并登录

    url:https://example.com/login
wait:1500
key:tab
text:my-user
key:tab
text:my-password
key:enter

    先等页面加载完再发键，否则按键会落到地址栏或别的窗口。

    常见错误排查

    • 报错 key:xxx is not mapped to any known key：键名不在上面的对照表里。核对拼写（对照表已不区分大小写），组合键用 + 连接。
    • 宏完全没反应：宏需要 keyboard 库（pip install keyboard，Windows 打包版已内置）；确认右上角「上位机动作」已开启，动作类型选的是「宏」且点过「应用配置」。
    • 组合键不生效：用 + 连接，key:ctrl+shift+t；不要写成 key:ctrl shift t 或 key:ctrl+alt t。
    • 输入跑到了别的位置：页面还没加载完，把 wait: 调大（如 wait:2000）。
    • 目标程序收不到按键：目标程序以管理员身份运行时，上位机也要以管理员身份运行。
    • Linux / macOS 下按键无效：keyboard 需要 root 权限（sudo python app.py）；不便提权时改用「执行命令」。
    • 网址没打开：url: 后面必须带 http:// 或 https://。
    • text: 输出了奇怪字符：受当前输入法影响，执行前先切到英文输入法。
